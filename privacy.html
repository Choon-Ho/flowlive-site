Flow Live 개인정보처리방침

시행일: 2026년 10월 2일 · 운영: FlowMedia

1. 수집하는 정보

Flow Live는 사용자가 "Google 계정 연결"을 누른 경우에만 Google OAuth를 통해 다음 권한을 요청합니다.

  • https://www.googleapis.com/auth/youtube.force-ssl — 사용자의 YouTube 채널 정보를 확인하고, 라이브 방송(liveBroadcasts)과 스트림(liveStreams)을 만들고 시작·종료하기 위해 사용합니다.

그 밖의 개인정보(연락처, 위치, 결제 정보 등)는 수집하지 않습니다.

2. 정보의 이용

받은 정보는 사용자가 앱에서 직접 요청한 라이브 송출 기능(채널 확인, 방송 생성, 스트림 연결, 방송 시작·종료)에만 사용합니다. 광고, 분석, 판매, 제3자 제공에 사용하지 않습니다.

3. 저장과 전송

  • Google 로그인 토큰은 사용자의 Mac 안 macOS 키체인에만 저장됩니다.
  • Flow Live는 이 정보를 FlowMedia나 다른 서버로 보내지 않습니다. 앱은 사용자의 Mac에서 Google/YouTube API와 직접 통신합니다.
  • 영상·음성은 사용자가 송출을 시작했을 때 사용자의 YouTube 송출 주소로만 전송됩니다.

4. Google API 서비스 사용자 데이터 정책 준수

Flow Live가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. Flow Live는 YouTube 서비스 약관에 따라 YouTube API 서비스를 사용하며, Google 개인정보처리방침(policies.google.com/privacy)이 함께 적용됩니다.

5. 연결 해제와 삭제

  • 앱의 송출 패널 "계정 연결 끊기" 또는 설정 ▸ Streaming의 "Disconnect"를 누르면 키체인에 저장된 토큰이 삭제됩니다.
  • Google 계정 보안 설정(myaccount.google.com/permissions)에서 언제든지 Flow Live의 접근 권한을 취소할 수 있습니다.
